# মাহমুদুর হাসান বিদ্যানিকেতন (MHB School Website)

**মাহমুদুর হাসান বিদ্যানিকেতন (MHB School)**-এর জন্য তৈরি একটি আধুনিক, ফার্স্ট-লোডিং ও রেসপন্সিভ স্ট্যাটিক ওয়েবসাইট। প্রজেক্টটি **Next.js 15 (App Router)** এবং **Tailwind CSS** ব্যবহার করে প্রস্তুত করা হয়েছে।

---

## 🚀 ফিচারসমূহ (Features)

- 📱 **সম্পূর্ণ রেসপন্সিভ ডিজাইন:** মোবাইল, ট্যাবলেট এবং ডেক্সটপ যেকোনো ডিভাইসে সহজে ব্যবহারযোগ্য।
- 🏫 **বিস্তারিত বিদ্যালয় তথ্য:** প্রতিষ্ঠানের পরিচিতি, ইতিহাস, লক্ষ্য ও উদ্দেশ্য সেকশন।
- 👨‍🏫 **শিক্ষক-শিক্ষিকাদের তালিকা:** শিক্ষকদের তথ্য ও পরিচিতি।
- 📢 **নোটিশ বোর্ড ও ইভেন্ট:** সর্বশেষ নোটিশ ও স্কুলের কার্যক্রম প্রদর্শন।
- 🎓 **ভর্তি ও একাডেমিক তথ্য:** ভর্তির নিয়মাবলী, ফি ও সিলেবাস সংক্রান্ত গাইডলাইন।
- 🖼️ **ফটো ও ভিডিও গ্যালারি:** বিদ্যালয়ের বিভিন্ন ইভেন্ট ও ক্যাম্পাসের ছবি।
- 📞 **যোগাযোগ ও ঠিকানা:** যোগাযোগের নম্বর, ঠিকানা ও ফর্ম।

## 🛠️ টেকনোলজি স্ট্যাক (Tech Stack)

- **Framework:** [Next.js 15](https://nextjs.org/) (App Router)
- **Library:** [React 19](https://react.dev/)
- **Language:** [TypeScript](https://www.typescriptlang.org/)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Icons:** [Lucide React](https://lucide.dev/)

```text
mhb-school-nextjs/
├── app/                  # Next.js App Router (Pages & Routes)
│   ├── about/            # বিদ্যালয় পরিচিতি পেজ
│   ├── academics/        # একাডেমিক সংক্রান্ত তথ্য পেজ
│   ├── admission/        # ভর্তি তথ্য পেজ
│   ├── contact/          # যোগাযোগ পেজ
│   ├── events/           # ইভেন্ট ও আয়োজন পেজ
│   ├── gallery/          # ছবি ও ভিডিও গ্যালারি পেজ
│   ├── notices/          # নোটিশ বোর্ড পেজ
│   ├── principal/        # অধ্যক্ষের বাণী পেজ
│   ├── teachers/         # শিক্ষকবৃন্দের তালিকা পেজ
│   ├── globals.css       # গ্লোবাল স্টাইল ও Tailwind CSS ফাইল
│   ├── layout.tsx        # মেইন অ্যাপ লেআউট (Header & Footer সহ)
│   └── page.tsx          # হোম পেজ (Landing Page)
├── components/           # পুনর্ব্যবহারযোগ্য UI কম্পোনেন্টসমূহ
│   ├── Header.tsx        # নেভিগেশন বার
│   ├── Footer.tsx        # ওয়েবসাইট ফুটার
│   └── PageHero.tsx      # পেজ হেডার/ব্যানার কম্পোনেন্ট
├── public/               # ইমেজ ও স্ট্যাটিক এসেট
├── tailwind.config.ts    # Tailwind CSS কনফিগারেশন
└── package.json          # প্রজেক্ট ডিপেনডেন্সি ও স্ক্রিপ্টসমূহ
```

## 💻 কীভাবে প্রজেক্ট রান করবেন (How to Run)

### ১. ডিপেনডেন্সি ইনস্টল করুন:
```bash
npm install
```

### ২. ডেভেলপমেন্ট সার্ভার চালু করুন:
```bash
npm run dev
```
এরপর ব্রাউজারে `http://localhost:3000` ঠিকানায় যান।

### ৩. প্রজেক্ট বিল্ড করুন (Static Export):
```bash
npm run build
```
বিল্ড সম্পন্ন হওয়ার পর `out/` ফোল্ডারে স্ট্যাটিক ওয়েবসাইট প্রডিউস হবে, যা যেকোনো স্ট্যাটিক হোস্টিংয়ে (যেমন: Vercel, Netlify, Cloudflare Pages) সরাসরি পাবলিশ করা যাবে।

## 📝 কনটেন্ট পরিবর্তন বা আপডেট

সকল টেক্সট ও ডামি কনটেন্ট সরাসরি `app/` এবং `components/` ফোল্ডারের ফাইলগুলোতে রাখা হয়েছে। যেকোনো নোটিশ, ইভেন্ট বা তথ্য আপডেট করতে সংশ্লিষ্ট পেজ ফাইলটি ওপেন করে পরিবর্তন করতে পারবেন।
